Cómo se ha grabado

El vídeo se genera automáticamente, sin editar, conduciendo un navegador sobre la aplicación en marcha. Las escenas de «API REST» muestran la petición y la respuesta reales del servidor para lo que no tiene pantalla en la interfaz (trayectoria contractual, baja, permisos cruzados).

docker compose up -d
(backend) sh ./mvnw spring-boot:run
(frontend) npm start
cd demo && node record-demo.mjs
python3 -I build-demo.py salida/*.webm salida/chapters.json .

Requiere una base de datos limpia, playwright y ffmpeg. Detalles en la cabecera de record-demo.mjs.
